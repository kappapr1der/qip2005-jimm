# Иконка для JimmStore

`qip.png` — настоящая иконка исходного QIP, извлечённая как ресурс PE без запуска клиента. Кадр 32×32 увеличен до требуемых магазином 128×128 с точным повторением пикселей, без сглаживания и дорисовки. Исполняемый файл не изменён.

В `provenance.json` записаны SHA-256 исходного клиента, извлечённого ICO и опубликованного PNG. Для повторного извлечения используется `scripts/extract_client_icon.py`; преобразование выполняется Pillow: `image.ico.getimage((32, 32)).convert('RGBA').resize((128, 128), Image.Resampling.NEAREST)`.

Права на изображение принадлежат соответствующим правообладателям QIP. Иконка исключена из MIT-лицензии собственного кода проекта; её публикация не означает независимого подтверждения прав на распространение оригинального клиента. См. `docs/THIRD_PARTY.md` и `docs/redistribution.md`.

Скриншоты в заявку не включены: официальный формат их не требует. Личные снимки экрана пользователей не публикуются.
