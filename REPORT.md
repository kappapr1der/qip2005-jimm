# Проверка версии 1.1.0

Локальный кандидат подготовлен 13 октября 2026 года в ветке `work/v1.1.0-update-agent`. Remote проверен: `https://github.com/kappapr1der/qip2005-jimm.git`; на момент аудита и финальной сверки репозиторий пустой. Удалённые ветки и Releases не менялись.

## Выполнено

- Нативный QIP Update Agent и Launcher: C++20/Win32, x64, 1,415,680 байт каждый. В импортах только системные DLL Windows: ADVAPI32.dll, bcrypt.dll, CRYPT32.dll, GDI32.dll, KERNEL32.dll, msvcrt.dll, ole32.dll, SHELL32.dll, USER32.dll, WINHTTP.dll. Обязательной установки дополнительных runtimes нет.
- Inno Setup 1.1.0: прежний AppId `{A94D4B7F-5D7B-4E78-BF72-C44A3AC98849}`, путь `%LOCALAPPDATA%\Programs\QIP2005`, режим `lowest`, версия файлов 1.1.0.0, обновление поверх старых данных. Бинарники QIP не менялись.
- Анонимный официальный API GitHub, SemVer, проверка раз в 24 часа, отдельный процесс сети, автоматическое скачивание, обязательная RSA/SHA-256-проверка и запрос установки. Автоматическая установка после выхода клиента — отдельная выключенная по умолчанию настройка.
- Подписанный манифест содержит 155 программных файлов. `Users` и изменяемые CFG не входят в список заменяемых пользовательских данных. Приватный ключ защищён DPAPI и находится вне Git и установщика.
- Резервная копия до ручного и автоматического обновления, восстановление файлов и собственного состояния удаления при сбое, отдельный Worker для замены своего EXE. Переходы через ссылки и рекурсивные резервные копии блокируются.
- Workflows для проверки PR, приватной сборки без публикации и подтверждённого стабильного выпуска. Публичная публикация полного клиента заблокирована до документального подтверждения прав.

## Фактические проверки

42 автоматических теста выполнены нативным harness и Python unittest, без ошибок и пропусков. GitHub API и выполнение ошибочного установщика мокированы; криптография, файловые снимки, восстановление и Win32-запуск вспомогательного процесса выполнялись реально.

Проверены отсутствие новых релизов, GitHub 404/403/503 и ошибка подключения, SHA-256 повреждённого установщика, неверная подпись и изменение подписанных байтов, отказ пользователя, более старая версия и защищённая верхняя версия, занятый QIP, повторная проверка после установки и восстановление после ошибки/несовпадения файлов. Проверены 24-часовой интервал, отключение проверок, явный ручной запрос, истечение манифеста, неправильный репозиторий/URL, обходы путей, запрещённые имена и попытка заменить оригинальные EXE/DLL. Замена существующего агента проверена из worker-harness вне папки приложения.

В тесте с приватными копиями реальных профилей проверено сохранение после успешной установки и восстановления после имитированного повреждения. Использованы копии 31 реальных файлов; содержимое и персональные имена не внесены в Git или журналы. Рабочее дерево профилей в исходной установке сверено с предварительной копией и осталось побайтно прежним.

16 проверок выполнены настоящими установщиками 1.0.0 и 1.1.0 в отдельной папке Windows 11. Для них намеренно использованы один общий тестовый AppId и отдельные имена ярлыков; производственный AppId подтверждён отдельно исходным скриптом. Проверены переход между версиями, реальные копии профилей и истории, исходные EXE/DLL, регистрация версии, ярлык Launcher, настройки обновлений, точная резервная копия, отсутствие административных прав, деинсталлятор с сохранением данных и уборка тестовой регистрации/ярлыков.

Два реальных запуска классического QIP выполнены через итоговый Launcher на чистой копии без аккаунтов: Launcher завершился за 50 и 52 мс, QIP создал окно и продолжал работать. Монитор завершился после выхода клиента. Вход в Jimm.online и отправка сообщений в этих тестах не выполнялись. Ранее работоспособность авторизации, переписки, трея, звуков, настроек и масштабирования версии 1.0.0 подтвердил пользователь; это пользовательское подтверждение, а не новая проверка этих функций агентом.

Во время первой интеграционной проверки ошибочно совпали имена двух тестовых и рабочих ярлыков. Оба рабочих ярлыка восстановлены из снимка с проверкой SHA-256. Тест исправлен на отдельное пространство имён и повторён. Рабочие профили и EXE при этом не изменялись. При первом smoke-запуске драйвер PowerShell ожидал всё дерево процессов через `Start-Process -Wait`; измерение исправлено на ожидание только процесса Launcher. Это изменения драйверов проверки, не клиента.

## Что ещё не доказано

GitHub Actions пока не запускались на удалённом runner, environments/required reviewers и secrets не настроены. Публичного Release нет. Полный сетевой цикл получения опубликованного подписанного обновления не проверялся: такого релиза ещё нет; ответы API в тестах мокированы. Полная автоматическая установка реального скачанного релиза штатным production Worker не запускалась; алгоритм транзакции проверен отдельным native harness, а настоящая установка — изолированными Inno-инсталляторами. Принудительное отключение питания не имитировалось; процедура восстановления проверена из полного снимка.

Интерактивные кнопки нового окна настроек и все диалоги согласия вручную не проходились. Вход в аккаунт, переписка, звуки, трей и масштабирование после обновления на рабочем пользовательском профиле не повторялись. Установщик и собственные EXE не имеют Authenticode-сертификата издателя; для обновлений используется подпись манифеста с закреплённым ключом.

Право публичного распространения исходного QIP, модификации и ресурсов не установлено. Собственная MIT-лицензия не заменяет эти права. См. [аудит](docs/redistribution.md), [выпуск](docs/build-and-release.md) и [машинные результаты](docs/validation-results.json).
