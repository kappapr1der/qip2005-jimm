# Проверка QIP 2005 Jimm 1.1.3

13 ноября 2026 года. В выпуск включено исправление, найденное при [аудите 1.1.1](AUDIT-1.1.1.md): подготовка профиля во время обновления больше не требует повторного захвата блокировки Install дочерним процессом. Передача новому помощнику проверяет активное подписанное задание и соответствие файлов. Ошибка помощника возвращает ненулевой код даже старому worker; новый worker дополнительно завершает подготовку перед отметкой успеха.

## Выполненные локальные проверки

При проверке опубликованного 1.1.2 настоящий старый worker безопасно откатил установку: путь к одному EXE имел другое представление Windows. 1.1.2 возвращён в черновики, его тег и файлы не заменяются. В 1.1.3 процесс сверяется по File ID и идентификатору тома, а не по строке пути или одному имени EXE. Другой файл с теми же байтами не считается тем же процессом.

До публикации кандидат 1.1.3 проверен неизменённым настоящим EXE агента 1.1.1, а не только перекомпилированной тестовой логикой. Он принял локально подписанный установщик, установил его, сохранил три синтетических файла профиля и истории; все 155 программных файлов совпали с манифестом. В журнале подтверждён путь `worker_path_alias_accepted`. Это локальная совместимость с настоящим worker, без заявления о сетевом скачивании ещё не опубликованного 1.1.3.

| Набор | Успешно |
|---|---:|
| Обновлятор, включая сохранение приватной копии данных | 43/43 |
| Запуск, копии и восстановление | 28/28 |
| Настоящие тестовые Inno, подписанные временным ключом; переход 1.1.1 → 1.1.3 | 30/30 |
| Поручение публикации, версия, источник и отсутствие ложного подтверждения прав | 11/11 |
| Полный установщик 1.1.1 → 1.1.3 на приватной копии профилей, затем деинсталляция | 16/16 |

Всего 128 проверок, без ошибок и пропусков. Сквозной тест проверил ожидание закрытия процесса, подпись RSA и SHA-256, откат намеренно повреждённой тестовой истории, незавершённый журнал, повторный запуск, отказ от повреждённых пакетов и совместимость с прежней логикой worker 1.1.1. Полный установщик проверен под токеном без прав администратора. Исходные байты приватной копии сверены до и после установки, кроме предусмотренных изменений HistPath/Startup; содержание в журналы не выводилось.

Установщик: `QIP2005-Jimm-Setup-1.1.3.exe`, 3902665 байт, SHA-256 `3c1457a46bc0b6a64e0300a05c9e456680754b697c4f2b4de33c22aa9014e8d9`. Манифест охватывает 155 программных файлов и подписан прежним локальным RSA-ключом; оригинальные qip.exe и docking.dll совпадают с предоставленным пакетом. Профили в дистрибутив не включены. Установщик не имеет Authenticode-подписи: подлинность обновления проверяет RSA-манифест с закреплённым публичным ключом.

## Область решения о публикации

После аудита владелец прямо поручил выпуск версии с изменениями. Решение привязано к 1.1.3 и SHA-256 исходного пакета. Публикация требует явного локального параметра `--owner-publication-decision`; независимые права на QIP этим решением не подтверждаются. Флаг `qip_redistribution_approved` остаётся `false`, автоматический workflow публикации без независимого основания закрыт. См. [redistribution.md](redistribution.md).

## Ограничения

В этом выпускном прогоне не повторялись авторизация настоящего аккаунта, переписка, звуки, трей и масштабирование. Ожидание закрытия настоящего QIP и настоящий GitHub-переход 1.1.0 → 1.1.1 проверялись в предшествующем аудите; текущий сквозной тест использует собственный управляемый процесс и локальный HTTP-адаптер. Фактический опубликованный переход 1.1.1 → 1.1.3 проверяется отдельно после появления артефактов в GitHub, его результат не предполагается заранее.

Восстановление приватного ключа на другом компьютере и после потери Windows не проверено. Существующие резервные копии не удаляются; политика хранения только предложена. Доработки панели задач и масштабирования окна настроек в 1.1.3 не включены.

Машинные результаты — в validation-1.1.3.json. Результаты GitHub CI и публичной проверки фиксируются в комплекте выпуска после их фактического завершения.
