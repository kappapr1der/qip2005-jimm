# Распространение QIP 2005 Jimm

13 ноября 2026 года владелец проекта подтвердил права на распространение предоставленной сборки и поручил опубликовать релиз. Основание зафиксировано в [документе подтверждения](permissions/owner-confirmation-2026-11-13.md); docs/redistribution.json содержит разрешающий флаг и путь к этому документу.

В Git хранятся исходники сопровождения, установщик, документация и тесты. Установочный EXE и чистый исходный пакет распространяются как файлы GitHub Release. Пользовательские профили, история, пароли и секрет подписи в публикацию не входят.

При первоначальном аудите 13 октября 2026 года разрешение не было предоставлено: в архиве отсутствовал соответствующий документ, а историческая ссылка на QIP EULA была недоступна. Эта прежняя отметка сохранена в исторических отчётах; текущее решение основано на последующем подтверждении владельца.

MIT-лицензия из корня относится только к собственному коду сопровождения. Оригинальный QIP, модификация и сторонние ресурсы сохраняют своих правообладателей; они перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
