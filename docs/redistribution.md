# Аудит распространения QIP

Проверка выполнена 13 октября 2026 года до реализации обновлятора.

Предоставленный архив содержит клиент, DLL, локализацию, скин, звуки и вспомогательный скрипт, но не содержит лицензии, разрешающей распространять именно эту модифицированную сборку. В ресурсах EXE указано `The Author of QIP`; данных о передаче прав автором модификации нет. Эти сведения не устанавливают владельцев всех компонентов и условия их передачи.

Историческая ссылка на [QIP EULA](http://wiki.qip.ru/EULA), найденная в бинарнике, недоступна при проверке. [Jimm.online](https://jimm.online/) предоставляет ссылки на загрузку клиента, но просмотренная страница не содержит разрешения на распространение данного пакета. Доступность загрузки и обозначение freeware не используются как доказательство права переупаковки или публикации модификаций.

Результат: права на публичное распространение **не подтверждены**. Это не вывод, что распространение запрещено при любых обстоятельствах; пригодного подтверждения для этого проекта пока нет. Потребуются условия или письменные разрешения для исходного QIP, внесённых модификаций и включённых сторонних ресурсов.

До подтверждения весь клиентский payload, DLL, иконки, звуки, скины, полный установщик и исходный пакет остаются локальными. В Git публикуется только собственная инфраструктура и лицензированный исходный header JSON. `docs/redistribution.json` содержит `false`; release workflow отказывает при этом состоянии.

После получения подтверждения владелец проекта должен сохранить проверенный документ в `docs`, указать его относительный путь в `evidence` и явно изменить флаг. Технический флаг сам по себе не создаёт права. Перед merge в `main` и публикацией по условию пользователя требуется отдельное подтверждение.

MIT из корня относится только к нашему коду. Чужие материалы перечислены в `THIRD_PARTY.md`, их лицензии сохраняются отдельно. Исходные права QIP этой лицензией не заменяются.
