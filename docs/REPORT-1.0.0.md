# Проверка QIP 2005 и установщика

Дата: 13 октября 2026 года. Источник: локальный архив `E:/Telegram Desktop/QIP2005_clean.7z`. Исполняемые файлы и скрипты из архива не запускались. Текст и справочные строки архивного скрипта рассматривались как данные.

## Статический анализ

Архив проверен командой 7-Zip `t`: ошибок нет. Перед распаковкой проверены пути: все записи находятся внутри `QIP2005_clean`, без абсолютных путей и переходов `..`. 14 каталогов, 151 файл, 4 619 492 байта после распаковки. Персональных аккаунтов или переписки в исходном `Users` нет: присутствует только `connect.cfg`.

SHA-256 архива: `0bcc0f2b0914f89af68200fd811e8c96b9f28fcbdac8ff034bdf02a81fd13a0c`.

`qip.exe`: PE32, Intel x86, Delphi/VCL, версия из ресурсов `8.0.9.7`, размер 3 393 024 байта. Есть секция модификации `.qipmod`. `Plugins/docking.dll` также PE32 x86. Оба файла не имеют Authenticode-подписи. PE-заголовки, секции, импорты, строки и ссылки на пути сохранены в `verification`.

SHA-256 `qip.exe`: `495b9cae959b1713a3857d6b6519309d94541d895eae98f3caf06a57226e4da8`. Файл не менялся. Встроенная самопроверка CRC32 совпала: `81f8d1f4`. В слоте CODEPAGE — `1251`. У клиента есть манифест Common Controls 6; запроса `requireAdministrator` в нём нет.

В составе находятся русская и английская локализации, скин ICQ5 со статическими и анимированными смайлами, 9 звуков WAV, иконки DS и плагин docking. Все 151 файл включены в пакет и при пробной установке совпали с оригиналом по SHA-256. Архивный `tools/qip_urls.py` сохранён как исходный вспомогательный файл; ни анализ, ни установщик его не выполняют.

## Соединение и другие адреса

`Users/connect.cfg` содержит `LoginServer=icq.jimm.online`, `LoginPort=5190`, `ProxyType=NONE`, `KeepAlive=1`. `LI/current.cfg` содержит `Russian` и `204`; `Skins/current.cfg` — `ICQ5` и `1`.

В модифицированном бинарном файле есть отдельные слоты обновлений:

- UPDATE: `http://qipupdate.home.arpa/newver.php`
- DOWNLOAD: `http://qipupdate.home.arpa/download/`
- PARAMS: `http://qipupdate.home.arpa:%s/params.txt`

Эти адреса уже были в предоставленном архиве и сохранены без изменений. В бинарнике также остаются исторические строки с `qip.ru`, `icq.com`, `aim.com` и ссылками библиотек. Наличие строки само по себе не доказывает, что адрес используется при работе. Полный сетевой трафик клиента не проверялся.

## Где сохраняются данные

Прослежена цепочка `TApplication.ExeName` → `ParamStr(0)` → `GetModuleFileNameA` → извлечение каталога → добавление `Users\connect.cfg`. Для языка и скина используется та же база. Адреса функций и ссылки приведены в `base-path-proof.txt`, `path-xrefs.txt`, `details.txt`.

| Назначение | Путь внутри папки установки | Защита установщика |
|---|---|---|
| Соединение | `Users/connect.cfg` | Только при отсутствии; сохраняется при удалении |
| Аккаунты, настройки, контакты и история | `Users/...`, включая `Accounts.cfg`, `Default.cfg`, `.clv/.cli/.clg` и `History` | Существующее дерево не импортируется и не перезаписывается; остаётся по умолчанию |
| Выбор и список языков | `LI/current.cfg`, `LI/langs.cfg` | Только при отсутствии; сохраняются при удалении |
| Выбор и список скинов | `Skins/current.cfg`, `Skins/skins.cfg` | Только при отсутствии; сохраняются при удалении |

Под `%LOCALAPPDATA%\Programs\QIP2005` эти пути доступны текущему пользователю. Доступ записи в `Users` проверяется самим установщиком перед копированием. Реальный стандартный путь дополнительно проверен тестовой установкой и записью синтетического файла без административных привилегий. Историю в другом каталоге, выбранном в самом клиенте, установщик не изменяет.

Фактические операции записи работающего QIP не наблюдались: клиент не запускался. Вывод о его стандартных путях основан на статическом коде и конфигурации; проверка прав касается целевых папок установщика.

## Поведение упаковки

Inno Setup 6.7.3. `PrivilegesRequired=lowest`, пользовательская регистрация удаления HKCU, стандартный каталог `%LOCALAPPDATA%\Programs\QIP2005`. Ярлыки с рабочим каталогом приложения создаются для текущего пользователя. Автозапуск — обычный ярлык в его Startup, отдельный флажок, по умолчанию выключен. При повторной установке снятие флажка удаляет ранее созданный установщиком ярлык.

Пять изменяемых CFG-файлов используют `onlyifdoesntexist uninsneveruninstall`. Деинсталлятор по умолчанию сохраняет профили и историю. Интерактивная очистка требует двух подтверждений с «Нет» по умолчанию. Тихая очистка возможна только с документированным отдельным параметром `/REMOVEUSERDATA=1`. Она удаляет только `Users` данной установки и четыре конкретных файла CFG языка/скина. Нет рекурсивного удаления всей папки приложения. Junction внутри дерева не обходится; ссылочные корневые каталоги очистки пропускаются.

Штатные программные ресурсы восстанавливаются при повторной установке и удаляются деинсталлятором. Пользовательские файлы под новыми именами остаются. Если вы вручную меняете штатные BMP/WAV/INI-файлы, сохраняйте резервную копию: они относятся к ресурсам приложения.

Рекламные компоненты, сторонние загрузчики, фоновые службы и задания планировщика не добавлены. Нет секции `[Run]`, автоматического запуска клиента, загрузки компонентов установщиком, изменений адресов или системных разрешений. Исполняемый файл и плагин сохранены побайтно. Поведение самого исходного клиента целиком не сертифицировалось.

## Выполненная проверка

Windows 11 Pro x64, `10.0.26100`, токен пользователя со средним уровнем целостности. Журнал Inno Setup подтверждает `User privileges: None`, `Administrative install mode: No`, корень регистрации `HKEY_CURRENT_USER`.

44 проверки в изолированном каталоге и 6 проверок стандартного пути завершились успешно. Проверены:

- Совпадение всех установленных файлов по SHA-256, включая EXE, DLL, русскую локализацию, звуки и скин.
- Ярлыки рабочего стола, меню «Пуск» и Startup: правильные цели и рабочий каталог.
- Регистрация удаления в HKCU без административных прав.
- Сохранение изменённых тестовых настроек и синтетической истории при повторной установке.
- Выключение выбранного ранее автозапуска и ярлыка рабочего стола.
- Удаление программы с сохранением аккаунтов, истории и изменённых CFG-файлов.
- Повторная установка поверх сохранённых данных.
- Явно запрошенная очистка тестовых профилей и CFG, сохранение внешнего каталога через junction и постороннего добавленного файла.
- Стандартный путь установки, выключенный автозапуск, доступ для записи и полное удаление чистой тестовой установки.
- Очистка тестовых ярлыков и регистрации. QIP не запускался.

Интерактивные окна установки и два окна согласия деинсталлятора проверены на уровне исходного скрипта и компиляции; ручной проход по их кнопкам не выполнялся. Проверки удаления выполнялись в тихом режиме, в том числе с явным параметром очистки.

Официальный компилятор получен по ссылке с сайта разработчика и проверен Authenticode: `Valid`, издатель `Pyrsys B.V.`. Он подготовлен в портативном режиме и сохранён отдельно от файлов, устанавливаемых клиенту. Пересборка автономна; готовый установщик не содержит компилятор.

Источники параметров Inno Setup: [пользовательские привилегии](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm), [флаги файлов](https://jrsoftware.org/ishelp/topic_filessection.htm), [удаление без обхода junction](https://jrsoftware.org/ishelp/topic_isxfunc_deltree.htm), [официальная проверка загрузок](https://jrsoftware.org/isdl-verify.php), [портативный режим компилятора](https://jrsoftware.org/ishelp/topic_technotes.htm).

## Границы результата

Собран полноценный проверенный установщик. Запуск клиента, вход в Jimm.online, отправка сообщений, функции docking, фактические сетевые обращения и поведение клиента с необычными именами профиля Windows не проверялись, поскольку неизвестный исполняемый файл не запускался. Сохранение всех файлов доказывает отсутствие изменений клиента, но не заменяет проверку его функций при работе. Полного аудита всех машинных инструкций или заключения об отсутствии вредоносного поведения нет.

Готовый установщик не подписан сертификатом издателя. SHA-256 выдаваемых файлов — в `SHA256SUMS.txt`.
