# QIP 2005 Jimm 1.1.1

Этот выпуск добавляет защиту от повторного запуска, резервные копии истории и обновление через GitHub. Его можно установить поверх прежней сборки.

## Что изменилось по сравнению с 1.0.0

- Повторный клик по ярлыку открывает уже работающий QIP, в том числе свёрнутый в трей.
- Исправлен двойной автозапуск: установщик убирает старую дублирующую запись QIP.
- Путь истории становится полным. Запуск из другой рабочей папки больше не должен мешать её сохранению.
- После выхода из QIP создаётся копия профиля и истории — не чаще раза в сутки, если данные изменились. Автоматическое копирование можно отключить.
- В «Настройках обновлений» появились кнопки для открытия истории, создания копии и восстановления. Перед восстановлением сохраняется свежая копия текущих данных. Старые копии автоматически не удаляются.
- Обновлятор проверяет новые версии отдельно от клиента. Установка ждёт закрытия QIP; полностью автоматический режим включается отдельно.

Оригинальный QIP, русский язык, привычный скин, звуки и подключение к Jimm.online сохранены.

## Как обновиться

Закройте QIP через меню «Выход», скачайте QIP2005-Jimm-Setup-1.1.1.exe из файлов этого релиза и запустите установщик. Затем пользуйтесь обычным ярлыком QIP.

Профили и сохранённая история остаются на месте. Сообщения, которые раньше не записались на диск, этот выпуск восстановить не может.
