# QIP 2005 Jimm 1.1.3

Исправлено автоматическое обновление из 1.1.1: подготовка профиля проходит и со старым агентом, даже если Windows возвращает разные представления пути к его EXE. При ошибке установки восстанавливаются прежняя версия и данные.

## По сравнению с 1.1.1

- Подготовка пути истории и настроек автозапуска больше не конфликтует с работающим процессом обновления.
- Рабочий процесс узнаётся по идентификатору файла Windows. Разная запись одного пути больше не вызывает ложный отказ от обновления.
- Ошибка подготовки профиля считается ошибкой установки. Восстанавливаются предыдущая версия, настройки и сохранённая история.
- Проверены обновление между версиями, ожидание выхода из QIP, повреждённый установщик, недействительная подпись и восстановление после сбоя. Добавлен автоматический сквозной тест с подписанными тестовыми пакетами.
- Ключ подписи остаётся на компьютере сопровождающего. Проверена его защищённая локальная копия; передача ключа в GitHub Secrets удалена.

Оригинальные qip.exe и docking.dll, русский язык, скины, звуки и адрес Jimm.online сохранены. Существующие резервные копии автоматически не удаляются.

## Как обновиться

Выйдите из QIP через меню «Выход», скачайте **QIP2005-Jimm-Setup-1.1.3.exe** из файлов релиза и установите поверх прежней версии. Профили и сохранённая история останутся на месте. Также можно воспользоваться «Настройками обновлений» → «Проверить сейчас»; установка дождётся выхода из QIP.

Промежуточный 1.1.2 снят со стабильной публикации после проверки настоящего перехода. Устанавливать его перед 1.1.3 не нужно.

Исходники и результаты проверок доступны в репозитории: [изменения относительно 1.1.1](https://github.com/kappapr1der/qip2005-jimm/compare/v1.1.1...v1.1.3), [отчёт проверки](https://github.com/kappapr1der/qip2005-jimm/blob/main/docs/REPORT-1.1.3.md).
