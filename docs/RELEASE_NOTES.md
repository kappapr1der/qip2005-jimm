# QIP 2005 Jimm 1.1.2

Исправлена ошибка автоматического обновления из 1.1.1: установщик мог сообщить об успехе, хотя подготовка профиля не выполнилась. Теперь этот шаг проходит и со старым агентом. Если он завершается ошибкой, обновление откатывается.

## По сравнению с 1.1.1

- Подготовка пути истории и настроек автозапуска больше не конфликтует с работающим процессом обновления.
- Ошибка подготовки профиля считается ошибкой установки. Восстанавливаются предыдущая версия, настройки и сохранённая история.
- Проверены обновление между версиями, ожидание выхода из QIP, повреждённый установщик, недействительная подпись и восстановление после сбоя. Добавлен автоматический сквозной тест с подписанными тестовыми пакетами.
- Ключ подписи остаётся на компьютере сопровождающего. Проверена его защищённая локальная копия; передача ключа в GitHub Secrets удалена.

Оригинальные qip.exe и docking.dll, русский язык, скины, звуки и адрес Jimm.online сохранены. Существующие резервные копии автоматически не удаляются.

## Как обновиться

Выйдите из QIP через меню «Выход», скачайте **QIP2005-Jimm-Setup-1.1.2.exe** из файлов релиза и установите поверх прежней версии. Профили и сохранённая история останутся на месте. Также можно воспользоваться «Настройками обновлений» → «Проверить сейчас»; установка дождётся выхода из QIP.

Исходники и результаты проверок доступны в репозитории: [изменения выпуска](https://github.com/kappapr1der/qip2005-jimm/pull/1), [аудит 1.1.1](https://github.com/kappapr1der/qip2005-jimm/blob/main/docs/AUDIT-1.1.1.md).
