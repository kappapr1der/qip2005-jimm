# QIP 2005 Jimm 1.1.0

Ярлыки теперь открывают QIP через Launcher. Классический `qip.exe`, плагин docking, русский язык, звуки, скин и сервер `icq.jimm.online:5190` сохранены.

Добавлена отдельная проверка GitHub Releases раз в 24 часа. Новый установщик скачивается автоматически, но запускается только после проверки подписи и SHA-256 и закрытия клиента. По умолчанию перед установкой требуется согласие; полностью автоматический режим включается в «Настройках обновлений».

Перед обновлением сохраняется копия приложения и пользовательских данных. При неудачной установке или несовпадении контрольных сумм предыдущая версия восстанавливается. Резервные копии остаются доступными пользователю.

Установка поверх 1.0.0 сохраняет профили и историю. Обязательное повышение прав, службы и задания планировщика не требуются. Целевая система — Windows 11 x64.
