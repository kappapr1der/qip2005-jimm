# Проверка 1.1.1 перед выпуском

13 ноября 2026 года. Подготовлены защита повторного запуска, резервные копии после выхода и ручное управление копиями. Установщик сохраняет существующий AppId и пользовательский каталог. qip.exe и Plugins/docking.dll не изменялись.

## Фактически выполнено

67 автоматических проверок: 42 проверки обновлятора и 25 проверок новых функций. Ошибок и пропусков локально нет. Приватная проверка использует копию реальных файлов, остающуюся вне репозитория; содержимое переписки и имена контактов в отчёты не включены.

Проверены конкурентные запуски, свёрнутое и скрытое окно Delphi, рабочая папка, миграция INI с сохранением кодировок, суточный интервал, отключение копий, ручное копирование, внешняя история, восстановление удалённого профиля, страховочная копия, повреждённые данные, обходы путей и восстановление прерванной операции. Тест сеанса вызывает штатный monitor с отключённой сетью и подтверждает создание копии только после выхода контролируемого клиента.

Настоящие установщики проверены в отдельном пространстве имён: 16 проверок перехода 1.0.0 → 1.1.1, 16 проверок 1.1.0 → 1.1.1 и 18 проверок тихого обновления с ранее включённым автозапуском. Профили и история проверены по SHA-256; разрешены только документированные изменения HistPath и Startup. Исходные байты дополнительно сохранены в снимке до установки. По умолчанию удаление оставляет данные.

Чистая копия оригинального QIP без аккаунтов запущена дважды через итоговый Launcher. Второй вызов показал существующее окно и сохранил единственный процесс; после завершения создалась одна копия профиля. Вход и переписка в этом тесте не выполнялись. В отдельном GUI-профиле проверены расположение элементов, кнопка ручной копии, список копий, запрос восстановления и появление страховочной копии; синтетический файл истории сохранился побайтно.

Рабочая установка владельца обновлена после его подтверждения о выходе из QIP. Перед установкой создана полная приватная копия. 48 пользовательских файлов сверены с ожидаемыми данными; оригинальные EXE/DLL сохранены. Эти приватные данные не публикуются.

## Ограничения проверки

GitHub API и ошибочная установка в большинстве сценариев обновления мокированы. Полный сетевой цикл штатного Worker с установкой именно опубликованного GitHub-релиза на рабочий аккаунт не имитировался. Повторная авторизация, переписка, звуки, трей и масштабирование на рабочем аккаунте не заявляются как новая отдельная проверка; классические файлы клиента совпадают с исходными. Перезагрузка Windows и принудительное отключение питания не выполнялись. Установщик не имеет Authenticode-сертификата издателя; обновления проверяются по подписанному манифесту с закреплённым ключом.

Машинные результаты — в validation-1.1.1.json. Права распространения подтверждены владельцем; основание находится в permissions/owner-confirmation-2026-11-13.md. Результат удалённого CI и ссылка на релиз фиксируются после публикации в комплекте выпуска.
