# QIP 2005 Jimm

## Установка в Windows 11

1. [Скачайте установщик из последнего релиза](https://github.com/kappapr1der/qip2005-jimm/releases/latest). Нужен файл с именем QIP2005-Jimm-Setup и расширением .exe.
2. Если QIP уже открыт, закройте его через меню «Выход».
3. Запустите установщик. При желании включите автозапуск вместе с Windows и резервные копии истории.
4. Откройте QIP ярлыком на рабочем столе или из меню «Пуск».
5. Введите свой UIN и пароль от [Jimm.online](https://jimm.online/). Если аккаунта ещё нет, зарегистрируйте его на сайте.

Для обновления установите новую версию поверх старой. Профили и сохранённая история останутся на месте.
